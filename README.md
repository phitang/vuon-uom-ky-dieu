# Vườn Ươm Kỳ Diệu

Game trồng hoa, lai giống và bán cây, lấy cảm hứng từ Plant Tycoon. Làm bằng Godot 4.

**Chơi ngay trên trình duyệt (cả iPhone):** https://phitang.github.io/vuon-uom-ky-dieu/

Trên iPhone: mở link bằng Safari → nút Chia sẻ → **Thêm vào MH chính** để chơi toàn màn hình và giữ tiến trình. Xoay ngang máy khi chơi.

## Nội dung

- Trồng hoa thời gian thực, tưới nước, bón phân, 3 loại đất.
- Lai giống bằng súng thụ phấn, gen trội/lặn, đột biến, Sổ tay sưu tầm.
- Shop cây: khách đi xem, trò chuyện ở quầy, tự đặt giá, trang trí shop.
- Vài khách ẩn chờ bạn tự khám phá.

## Thư mục

- `scripts/`, `scenes/`, `art/`, `music/`, `fonts/`: mã nguồn và tài nguyên game (mở `project.godot` bằng Godot 4).
- `docs/`: bản web đã xuất, dùng cho GitHub Pages.
- `HUONG_DAN.md`: hướng dẫn chi tiết (xuất APK Android, chỉnh số liệu, cấu trúc dự án).

Phông chữ Lora theo giấy phép SIL OFL (`fonts/OFL-Lora.txt`).
